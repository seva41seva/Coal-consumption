# Тепло — расчёт расхода угля

Адаптивное офлайн-веб-приложение (PWA), повторяющее расчётную логику Telegram-бота. Интерфейс на русском, ориентирован на телефон Android. Использует встроенные таблицы температур и не требует Telegram, учётной записи или сервера после первой загрузки.

## Запуск для проверки

Откройте `index.html` в браузере. Для проверки установки PWA и работы Service Worker нужен сайт по HTTPS (или localhost).

## Установка на Android

1. Разместите содержимое этой папки на HTTPS-хостинге (например, статический хостинг). Не переименовывайте отдельно файлы `manifest.webmanifest`, `sw.js` и иконки.
2. Откройте адрес сайта в Chrome на Android.
3. Выберите «Установить приложение» (либо меню ⋮ → «Добавить на главный экран»).
4. После первого открытия приложение кэшируется и затем работает офлайн.

Это PWA, а не APK: для установки из Google Play или как APK потребуется отдельная упаковка и подпись.

## Что перенесено

- Температура воздуха: целое число от −35 до +8 °C.
- Расход подпитки: любое неотрицательное число м³ (принимаются точка и запятая).
- Подача, обратка, базовый расход, уголь на подпитку и общий расход т/сутки.
- Обработка ошибок и очистка формы.
- Все исходные табличные значения перенесены из `bot5.py`; формула итогового расхода сохранена: базовый расход + (расход подпитки × кг угля на 1 м³) / 1000.



### Редактирование таблиц

В `index.html` данные `COAL_DATA` и `COAL_PER_M3` записаны построчно в квадратных скобках: в первой таблице строка имеет вид `[температура, подача, обратка, расход]`, во второй — `[температура, кг угля на 1 м³]`. Редактируйте строки таблиц; блоки `*_BY_TEMP` ниже формируют индексы для вычислений автоматически. После правки обновите версию кэша в `sw.js` (например, `teplo-calc-v2` → `teplo-calc-v3`) и загрузите всю папку проекта на хостинг.
