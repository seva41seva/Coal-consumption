# Тепло — расчёт расхода угля

Адаптивное офлайн-веб-приложение (PWA), повторяющее расчётную логику Telegram-бота. Интерфейс на русском, ориентирован на телефон Android. Использует встроенные таблицы температур и не требует Telegram, учётной записи или сервера после первой загрузки.

## Установка на Android

1. Разместите содержимое этой папки на HTTPS-хостинге (например, статический хостинг). Не переименовывайте отдельно файлы `manifest.webmanifest`, `sw.js` и иконки.
2. Откройте адрес сайта в Chrome на Android.
3. Выберите «Установить приложение» (либо меню ⋮ → «Добавить на главный экран»).
4. После первого открытия приложение кэшируется и затем работает офлайн.
